## ДЗ на выходные

Во всех задачах: функция + docstring с протоколом + тесты через assert. Без тестов не засчитывается. Сдача до понедельника.

1. **Решето Эратосфена.** Ввод N ≤ 10000, вывести все простые до N и их количество.
2. **Массив с top.** Ввод чисел до 0 с защитой от переполнения (`top == len(A)` → «массив заполнен», стоп). Вывести прямо и в обратном порядке.
3. **Ловушка ссылок.** Предсказать вывод до запуска, объяснить, исправить:

```python
A = [[0] * 3] * 3
A[0][0] = 1
print(A)
```

4. **copy_reversed из практики** — доделать, если не успел, плюс вариант `copy_array(A)` (прямая копия).
5. `*` **Сдвиг на k позиций** двумя способами: k одиночных сдвигов vs три разворота (`invert_array` трижды). Сравнить число операций.
6. `*` Задачи на judge.mipt.ru (`mipt_cs_on_python3`) — 2–3 задачи темы «Массивы».

7. **Второй максимум.** Найти второй по величине элемент массива за **один** проход циклом (без сортировки). Если его нет (все элементы равны или массив короче двух) — вернуть `None`.
   ```python
   assert second_max([1, 5, 3, 5, 2]) == 3   # 5 встречается дважды, второй — 3
   assert second_max([7, 7, 7]) is None
   ```

8. **Сдвиг вправо на k без нового массива.** `rotate_right(A, k)` — на месте, три разворота: весь массив, первые k элементов, остаток. Используй `invert_array` из практики.
   ```python
   A = [1, 2, 3, 4, 5]
   rotate_right(A, 2)
   assert A == [4, 5, 1, 2, 3]
   # учти случай k > len(A)
   ```

9. **Удалить все вхождения.** `remove_all(A, x)` — удалить из массива все элементы, равные x, сдвигом (на месте), вернуть новую длину. Порядок оставшихся сохранить.
   ```python
   A = [1, 2, 1, 3, 1]
   n = remove_all(A, 1)
   assert n == 2
   assert A[:n] == [2, 3]
   ```

10. **Мини-база на top.** Дополни задачу про `top`: после ввода до 0 реализуй команды пользователя — `push x` (добавить), `pop` (убрать последний, вывести его), `print` (вывести заполненную часть), `exit`. Размер массива 10, защита от переполнения и от pop из пустого.

11. **Счётчики простых.** По решету Эратосфена построй массив `count[i]` — количество простых чисел от 2 до i. Затем на q запросов вида `l r` отвечай, сколько простых на отрезке [l, r], **без перебора** (за O(1) на запрос).
    ```
    Ввод:  20 2
           5 10
           2 20
    Вывод: 2       # простые на [5,10]: 5, 7
           8       # простые на [2,20]: 2,3,5,7,11,13,17,19
    ```
